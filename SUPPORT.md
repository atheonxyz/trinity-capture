# Support

For installation or product help:

1. Confirm Node.js 20 or newer is installed.
2. Confirm the plugin is installed for your user, not only the current project.
3. Run the product's Trinity connect command again.
4. Check that the repository is enabled in a Trinity project.

Open a GitHub issue for reproducible plugin bugs that do not contain private session content. For account, billing, or data questions, email hi@usetrinity.ai.

Security issues must follow [SECURITY.md](SECURITY.md).
