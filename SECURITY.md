# Security policy

Please do not open public issues for suspected vulnerabilities.

Send a report to hi@usetrinity.ai with:

- Affected plugin and version.
- Reproduction steps or a proof of concept.
- Expected impact.
- Any suggested mitigation.

We will acknowledge reports as soon as practical, investigate them privately, and coordinate disclosure after a fix is available.

Supported versions are the latest published Marketplace version and the current `main` branch.
